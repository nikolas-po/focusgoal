## Описание

FocusGoal — локальное настольное приложение (Python + PyQt5). Данные хранятся в PostgreSQL на той же машине. Интернет-соединение не требуется. Приложение реализует:

- Управление целями с дедлайнами, приоритетами и статусами
- Трекер привычек (ежедневные, еженедельные, ежемесячные; бинарный и количественный режим)
- Поиск по всем полям целей и привычек в реальном времени
- Режим фокуса с таймером и блокировкой отвлекающих приложений
- Уведомления о дедлайнах и напоминания о привычках
- Статистику и экспорт данных (PDF, CSV, JSON)
- Шифрование бэкапов (AES-256), хэширование паролей (bcrypt)

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/nikolas-po/focusgoal.git
cd focusgoal
```

### 2. Создать виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Настроить базу данных

```sql
CREATE DATABASE focusgoal_db;
CREATE USER focusgoal_user WITH PASSWORD 'ваш_пароль';
GRANT ALL PRIVILEGES ON DATABASE focusgoal_db TO focusgoal_user;
```

### 5. Создать файл .env

```
DB_HOST=localhost
DB_PORT=5432
DB_NAME=focusgoal_db
DB_USER=focusgoal_user
DB_PASSWORD=ваш_пароль
ENCRYPTION_KEY=случайная_строка_32_символа
```

Сгенерировать ключ шифрования:

```bash
python3 -c "import secrets; print(secrets.token_hex(16))"
```

### 6. Применить миграции

```bash
python -m alembic upgrade head
```

## Архитектура

Приложение построено по принципу разделения на слои.

**Слой интерфейса** — PyQt5-виджеты и окна. Не содержат бизнес-логики.

**Сервисный уровень** — сервисы Python. Вся бизнес-логика: валидация, расчёт серий привычек, проверка дедлайнов, отправка пароля.

**Уровень репозитория** — репозитории. Изолированный доступ к БД через SQLAlchemy ORM. Параметризованные запросы.

**Уровень данных** — PostgreSQL. DDL-скрипты в `scripts/focus_goal_bd.sql`.

| Таблица | Назначение |
|---------|------------|
| users | Пользователи, хэш пароля, настройки |
| goals | Цели с дедлайнами и приоритетами |
| habits | Привычки, серии, режим |
| focus_sessions | Записи фокус-сессий |
| completion_log | Журнал выполнений |
| blocked_apps | Список блокируемых приложений |
| notification_schedule | Расписание уведомлений |
| system_log | Журнал системных событий |

Полный DDL-скрипт: `scripts/focus_goal_bd.sql`

## Тестирование

## Уведомления без systemd-таймера

По умолчанию уведомления отправляются через встроенный APScheduler, который стартует вместе с приложением. Systemd-таймер — опциональный компонент для уведомлений когда приложение закрыто.

Настройки: раздел «Настройки» → вкладка «Уведомления».

- Включить уведомления — глобальный переключатель
- Уведомления о целях — напоминания о дедлайнах
- Уведомления о привычках — ежедневные напоминания
- Уведомления о фокус-сессиях — сигнал по завершении сессии
- Тихий режим — диапазон времени без уведомлений

## Поиск по всем полям

В окнах «Цели» и «Привычки» реализован мгновенный поиск (debounce 300 мс).

Цели: название, описание, приоритет (текст), статус (текст), дедлайн (дд.мм.гггг).

Привычки: название, описание, тип, режим, статус, текущая серия.
